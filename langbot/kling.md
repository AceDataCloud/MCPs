## Kling

Generate video, animate a still, extend a clip, or apply motion and lip sync.

1. Open [Ace Data Cloud Applications](https://platform.acedata.cloud/console/applications?utm_source=langbot&utm_medium=referral&utm_campaign=evergreen) and copy an application API key with access to Kling.
2. Install this server from [LangBot Space](https://space.langbot.app/market/acedatacloud/kling). Paste the key into the private token field without the `Bearer` prefix. LangBot supplies that prefix when it connects.
3. Enable the server for your agent. Run `kling_list_actions` to explore the supported operations. Use `kling_get_task` with an existing task ID to retrieve the video.

Media generation uses Ace credits. [View service pricing](https://platform.acedata.cloud/models?utm_source=langbot&utm_medium=referral&utm_campaign=evergreen).
