# ACE Music on Glama

Open the [ACE Music MCP server on Glama](https://glama.ai/mcp/servers/AceDataCloud/AceMusicMCP) and check that its repository is AceDataCloud/AceMusicMCP. The remote Streamable HTTP endpoint is `https://acemusic.mcp.acedata.cloud/mcp`. For local stdio launch `uvx mcp-acemusic` and set `ACEDATACLOUD_API_TOKEN` privately. Start with `acemusic_list_models` before submitting a paid song. [Application keys](https://platform.acedata.cloud/console/applications)

## 中文操作指南

打开上面的 Glama 服务入口，确认仓库属于 AceDataCloud。添加远程地址后使用 MCP 客户端登录，或在本地使用应用密钥。可先查询模型，提交音乐任务后保留原任务 ID 查询。[中文安装说明](README_zh_Hans.md)
