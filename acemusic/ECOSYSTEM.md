# ACE Music integrations

Choose an integration for songs, lyrics, reference MP3 imports, covers, two-reference mashups and task retrieval. A new creation can spend account credits. Save the original task ID to check progress or resume an interrupted session.

## Published entry points

| Where you work | Install or connect |
| --- | --- |
| Browser | [ACE Music Studio](https://studio.acedata.cloud/acemusic) |
| HTTP API | [ACEMusicAPI](https://github.com/AceDataCloud/ACEMusicAPI) · [Markdown guide](https://docs.acedata.cloud/en/guides/acemusic/acemusic_audios.md) · [OpenAPI](https://docs.acedata.cloud/openapi/acemusic.json) |
| MCP client | [Hosted setup](https://platform.acedata.cloud/documents/mcp-acemusic) · [Local Python package](https://pypi.org/project/mcp-acemusic/) · [Tool directory](https://acemusic.mcp.acedata.cloud/.well-known/mcp/server-card.json) |
| VS Code | [ACE Music extension in Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=acedatacloud.mcp-acemusic) |
| Agent Skills | [Install the service Skill](https://skills.sh/acedatacloud/skills/ace-music) · [Skill source](https://github.com/AceDataCloud/Skills/blob/main/skills/ace-music/SKILL.md) |
| Terminal and applications | [AceMusicCli](https://github.com/AceDataCloud/AceMusicCli) · [CLI package](https://pypi.org/project/acemusic-cli/) · [Python, TypeScript and Go SDKs](https://github.com/AceDataCloud/SDK) |
| Self-hosted n8n | [ACEMusicN8N](https://github.com/AceDataCloud/ACEMusicN8N) · [community package](https://www.npmjs.com/package/@acedatacloud/n8n-nodes-acemusic) |
