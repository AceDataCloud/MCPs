# LobeHub 的 ACE Music 插件

从 [服务目录](https://lobehub.com/mcp/acedatacloud-acemusicmcp) 或手动导入 [HTTP 配置](install-http.json)，在客户端完成 OAuth；支持私有请求头的客户端也可配置 Bearer 应用密钥。桌面本地使用 [stdio 配置](install-stdio.json)，在私有设置中替换密钥。打开[应用控制台](https://platform.acedata.cloud/console/applications?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen&utm_content=acemusic_lobehub_api_key) 的 General application → Manage Keys 获取密钥。先查模型，再按需提交，后续查询复用原任务 ID。
