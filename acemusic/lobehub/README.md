# ACE Music for LobeHub

Open the [directory entry](https://lobehub.com/mcp/acedatacloud-acemusicmcp) or import [the HTTP configuration](install-http.json) and complete OAuth in the client. Clients that support private headers may use a Bearer application key. On desktop, import [the local stdio configuration](install-stdio.json) and replace the placeholder in private settings. Get the key under General application → Manage Keys in [Applications](https://platform.acedata.cloud/console/applications?utm_source=opensource&utm_medium=referral&utm_campaign=evergreen&utm_content=acemusic_lobehub_api_key). List the models first. Save each submitted song's task ID and query that ID.
