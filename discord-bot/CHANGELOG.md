# Changelog

## [2026.8.1.1] - 2026-08-01

### Added
- Initial release
- `discord_whoami` tool to view the proxied Discord account
- `discord_list_guilds` tool to list all joined servers
- `discord_list_channels` tool to list server channels
- `discord_create_text_channel` tool to create text channels
- `discord_list_members` tool to list server members
- `discord_send_message` tool to send messages (with optional reply)
- `discord_read_messages` tool to read recent channel messages
- `discord_edit_message` tool to edit sent messages
- `discord_delete_message` tool to delete messages
- `discord_search_messages` tool to search messages in a channel
- `discord_add_reaction` tool to add emoji reactions
- `discord_pin_message` tool to pin messages
- `discord_create_dm` tool to open DM channels
- `discord_send_dm` tool to send direct messages
- `discord_get_usage_guide` tool for comprehensive documentation
