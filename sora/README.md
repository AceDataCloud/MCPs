# SoraMCP

> **Status:** Retired

This repository is retained as historical source code. The Sora MCP integration is retired and is not available for new connections.

Do not use the former hosted endpoint or install the package for a new integration. Choose an active video MCP from the [Ace Data Cloud MCP directory](https://platform.acedata.cloud/mcps) instead.

Existing source and release artifacts remain available only for audit and migration purposes. No service availability or compatibility is guaranteed.
